1. Go to terminal\
2. Install the required packages: using pip install alpaca-py matplotlib numpy\
3. Go to Alpaca to get your api keys\
4. Once you have your keys run this in terminal:\
export API_KEY="YOUR KEY"\
export SECRET_KEY="YOUR "KEY

\
5. Run python3 mlsignal_terminal.py\
\
Features:\
Allows you to backtest random forest model for any ticker.
Shows drawdown, PCA
Connects to your alpaca paper trading system and trades there
